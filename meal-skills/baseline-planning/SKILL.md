# Baseline Planning and Report Drafting

## Purpose and Trigger
Support Education baseline construction across three bounded modes without inventing starting values, approving targets, or asserting causal attribution:
1. **Planning Mode**: Design a prospective (or delayed) baseline plan covering what to measure, for whom, when relative to academic terms and program exposure, from which sources, and what ethics/EMIS permissions are required.
2. **Existing-Report Coverage Mode**: Map framework indicators to a supplied baseline report's values, sources, reference periods, definitions, and disaggregations, flagging comparability gaps.
3. **Baseline Report Drafting Mode**: When empirical baseline findings, sample methodology notes, and tools are supplied, draft an editable 10-section Education Baseline Report preserving all limitations and unresolved target-validation questions.

Follow any baseline report draft with independent `baseline-report-review`. Apply [Epistemic Contract](../../meal-references/epistemic-contract.md), [Education MEAL Standards](../../meal-references/education-meal-standards.md), and [Funder Formats](../../meal-references/funder-formats.md).

## Minimum Inputs
- Logframe, results framework, indicator list, or `project-context/indicator-ledger.md`.
- Target learner/educator population, education sub-sector, and geographic scope, if known.
- Program start/first-exposure timing and academic term dates (or explicit note that timing is unknown).
- For Report Drafting or Coverage Mode: empirical baseline data extracts, fieldwork notes, or baseline report draft.

State the active intake mode (`project-context/`, designated folder, or explicit files) and exact files reviewed. Supplied dates govern; if date status relative to execution is unverified, write `"status unknown from supplied files"`.

## Procedure
1. **Confirm Mode and Intake**: Identify whether the task is Planning, Existing-Report Coverage, or Report Drafting, plus program stage, academic calendar, and first-exposure dates.
2. **Extract Framework Indicators**: Preserve exact wording, IDs, source-specific level labels, operational definitions, target learner/educator populations, units, academic observation windows, equity disaggregations, and targets with Evidence IDs (`filename#heading`, page, table, row). Never equate targets with baselines or silently rewrite indicators.
3. **Define Eligible Frame and Unit**: Specify eligibility rules, school vs. household unit of analysis, grade/age cohorts, and geographic boundaries. Flag gaps where logframe population differs from reachable school/EMIS frames.
4. **Map Measurement Sources and Permissions**: Classify each indicator to EMIS/administrative records, LMS logs, standardized learning assessments (e.g., EGRA/EGMA, competency rubrics), classroom observations, surveys/FGDs, or undecided. Mark a source available ONLY when institutional/Ministry/school access and IRB/ethics permissions are documented.
5. **Assess Prior Data Comparability**: Compare any candidate baseline data across construct/definition, learner eligibility, geography, unit, academic timing/season, assessment language, tool/mode, recall window, disaggregation, and VIPRT quality. Report material differences; existing data are not automatically a valid baseline.
6. **Check Exposure Timing and Academic Calendar**:
   - Plan prospective baselines before first exposure and aligned to academic terms/exam schedules.
   - If exposure already occurred, never label post-exposure collection or recalled pre-program ratings as a measured baseline. Offer labeled options: pre-exposure EMIS/administrative proxies, prospective baseline for a newly entering cohort, retrospective recall labeled strictly as supplementary self-report, or labeling the collection as Round 1 monitoring.
7. **Specify Sampling, Panel/Comparison Arms, and Ethics**: State frame, school/classroom clustering, and attrition assumptions only where supported; leave sample sizes undecided when design inputs are missing. Map every arm/cohort for comparison or panel designs without assuming baseline equivalence. Record Ministry/IRB review, parent consent, child assent, and minor PII protections as confirmed, unconfirmed, or required.
8. **Check Later-Round Comparability**: Verify tools, administration timing, cohort tracking vs. cross-sectional rules, and equity categories will hold at midline/endline; flag any needed crosswalks (`MEAS-D*`).
9. **Assemble Deliverable**:
   - **Planning Mode**: Use [Baseline Matrix Template](./template.md) across the 9-part planning output (purpose/sources; epistemic register; indicator coverage matrix; prior-evidence comparability; sampling/comparison decisions; tools/QA/safeguards/permissions; timing/roles; unresolved decisions; checklist).
   - **Existing-Report Coverage Mode**: Return the coverage matrix, source register, scope limits, and exact standalone headings `## Critical Issues`, `## Important Issues`, and `## Minor Improvements`.
   - **Report Drafting Mode**: Draft the 10 standard Education Baseline Report sections (Executive Summary; Introduction & Background; Methodology & Sampling; Indicator Coverage Table; Education Context Analysis; Target Population & Equity Profile; Findings Organized by Outcome Area; Data Quality & Attrition Notes; Target Validation & Program Recommendations; Annexes/Unresolved Decisions) using supplied data only.

## Measurement and Comparability Rules
- A baseline is an empirical measurement tied to a defined indicator, population, method, and academic window; it is never an estimate, target, or planned survey.
- Never invent a baseline of zero for an existing condition; an output count starts at zero only if definitions and records confirm no prior delivery.
- Distinguish unique learners from attendance events, and distinguish assessment dates from reference/recall periods.
- A descriptive baseline does not require a comparison group; never invent a counterfactual design when none is authorized.

## Missing, Conflicting, or Unsuitable Inputs
- **No indicator list**: Return a bounded planning shell listing framework inputs required.
- **Unknown exposure/term timing**: Mark baseline timing unresolved and request exact start and school-term dates.
- **Conflicting indicator definitions or versions**: Display both versions with Evidence IDs; if signed vs. unsigned conflict exists, treat signed as working baseline (`proposed`) and flag governing decision (`MEAS-D*`).
- **Missing sampling inputs**: Map indicators and decisions; do not compute a sample size.
- **Non-MEAL request**: State scope and stop.

## Completion Checklist
- Every supplied indicator is mapped or marked unassessable with exact wording preserved.
- Exposure timing, academic window, cohort vs. cross-sectional design, and source permissions are explicit.
- Post-exposure recall is never labeled a measured baseline.
- Safeguarding, guardian consent, child assent, and minor PII handling are addressed or flagged required.
- No baselines, targets, sample sizes, or approvals were fabricated.
