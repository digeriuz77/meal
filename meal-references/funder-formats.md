# Funder Formats and Education Document Discovery Patterns

Use this reference when aligning frameworks, drafting plans or reports, or scanning a project folder for Education MEAL/MERL documents.

## 1. Results Hierarchy Terminology Mapping

Different funders and ministries use different labels for the same logical hierarchy. Map terms to the standard hierarchy before reviewing or cross-checking, and preserve the funder's preferred labels when drafting:

| Concept | Results Framework Format | LFA Format | Impact-Outcome-Output Format | UN Format | Common Alternative |
|---|---|---|---|---|---|
| **Goal** | Goal | Overall Objective | Impact | Pillar / Goal | Strategic Objective |
| **Outcome** | Purpose / Intermediate Result (IR) | Specific Objective | Outcome | Priority / Outcome | Immediate Outcome |
| **Output** | Sub-IR | Result / Expected Result | Output | Output | Sub-Result / Deliverable |
| **Activity** | Activity | Activity | Activity | Activity | Work Package |
| **Indicator** | Performance Indicator | Objectively Verifiable Indicator (OVI) | Indicator | Indicator | KPI / Metric |
| **Data Source** | Data Source | Source of Verification (SoV) / Means of Verification | Source | Means of Verification (MoV) | Data System |
| **Assumption** | Assumption | Assumption / Pre-condition (activity level) | Assumption | Assumption | External Factor |

### Logical Framework Approach (LFA) Specifics
- LFA documents use **Intervention Logic** (rather than Narrative Summary), **OVIs**, **Sources of Verification**, and **Pre-conditions** at the activity level.
- Standard LFA design requires **one Specific Objective** per logframe and typically **3 to 6 Results**. Do not penalize LFA documents for following these conventions.

## 2. Funder M&E and Reporting Format Expectations

When a document, RFP, or user specifies a funder format, check compliance against these expectations alongside general quality standards:

| Format | Plan & Design Expectations | Reporting & Evaluation Expectations |
|---|---|---|
| **Results Framework & PIRS Format** | Results framework, activity M&E/MEL plan, Collaborating-Learning-Adapting (CLA) approach, standard indicators, Performance Indicator Reference Sheets (PIRS), Data Quality Assessment (DQA), midterm/final evaluation | Funder standard indicators, alignment with active M&E plan, evidence-based narrative, gender/equity analysis, annual/quarterly progress updates |
| **LFA Format** | Logical Framework Approach, intervention logic, OVIs, Sources of Verification, pre-conditions | Results-oriented monitoring format, OVI achievement vs. targets, assumptions tracking, OECD-DAC evaluation criteria |
| **Theory of Change & Value-for-Money (VfM)** | Explicit Theory of Change, logframe milestones, VfM across 4 Es (Economy, Efficiency, Effectiveness, Equity) | Annual review scoring against milestones, VfM assessment, adaptive learning documentation |
| **UN / Multilateral Format** | Results-based management (RBM), UNEG evaluation norms, gender-responsive and disability-inclusive M&E, SDG 4 alignment | Results-based reporting, SDG 4 / equity disaggregation, learning and lessons narrative |
| **Development Bank Format** | Results framework, independent evaluation standards, institutional/EMIS strengthening | Development effectiveness reviews, rigorous attribution/contribution transparency |
| **Grant Performance Framework** | Performance framework, KPI definitions, independent local verification | Progress update and disbursement linkage, programmatic-financial burn-rate reconciliation |
| **Foundations & Education Pooled Funds** | Learning-focused results model, equity targets, pragmatic collection burden | Outcomes and learning narrative, adaptation rationale, transparent limitations |
